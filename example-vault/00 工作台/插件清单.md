# 这套工作区，用了什么

| 插件 | 用途 | 版本 |
| --- | --- | --- |
| Study Club | 学习手账、自测、间隔复习 | 0.1.1 |
| Claudian | AI 协作 | 2.3.16 |
| Dataview | 动态知识索引 | 0.5.68 |
| Tasks | 跨笔记任务汇总 | 8.4.0 |
| Calendar | 日记日历 | 1.5.10 |
| Kanban | 项目看板 | 2.0.51 |

主题为 Study Club；Canvas、双向链接、关系图、搜索、Daily notes 和 Templates 使用 Obsidian 内置功能。

此开源仓库提供 Study Club 插件与主题；其余社区插件请在 Obsidian 的社区插件市场按名称安装。

| 插件 | 官方源码与许可证 |
| --- | --- |
| Claudian | https://github.com/YishenTu/claudian |
| Dataview | https://github.com/blacksmithgu/obsidian-dataview |
| Tasks | https://github.com/obsidian-tasks-group/obsidian-tasks |
| Calendar | https://github.com/liamcain/obsidian-calendar-plugin |
| Kanban | https://github.com/mgmeyers/obsidian-kanban |

Claudian 的模型调用尚未验证成功，需要自己的可用服务。
