# 让笔记，自己排好队

Dataview 实时读取「01 知识库」，不需要手工复制标题。

```dataview
TABLE WITHOUT ID file.link AS "学习卡片", sc-domain AS "领域", sc-topic AS "主题", sc-status AS "状态", sc-due AS "复习日期"
FROM "01 知识库"
WHERE sc-kind = "card"
SORT sc-domain ASC, sc-topic ASC, file.name ASC
```
